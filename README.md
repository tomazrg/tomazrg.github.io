# Ricardo G. Tomáz — Personal Website

My personal website, where I share my research on plant disease epidemiology, projects, and a few thoughts along the way.

🌐 **Website:** https://tomazrg.github.io

## What's inside

- **Research** on plant disease epidemiology, quantitative modeling, and computer vision for crop protection
- **Publications** and **projects** on soybean, rice, and maize diseases
- **Blog** posts on distributed lag models, EpiExposure, and research life
- **EpiExposure**, an R package for exposure–lag–response analysis ([docs](https://tomazrg.github.io/EpiExposure/))

## How it's built

A static site (HTML, CSS, and JavaScript) hosted on GitHub Pages. All content lives in JSON and Markdown files under `data/`, so updating the site means editing text files rather than code.
